# Runtime DS47 Parameter Management for SINAMICS V20
Scalable DS47 acyclic communication framework for Siemens S7-1200 PLC and multiple SINAMICS V20 drives using Modbus RTU.
<img width="1152" height="648" alt="Overview" src="https://github.com/user-attachments/assets/c0afb3e1-78e1-4181-a5b8-d78750d417b2" />

## Features
- Runtime parameter reading/writing
- Multi-drive scheduling
- HMI parameter programming
- DS47 telegram handling
- Runtime diagnostics
